# Getting help

Thanks for using The Protobuf Project. Here is where each kind of question gets
answered fastest.

## Start with the docs

- **[the-protobuf-project.org](https://the-protobuf-project.org)**: what the project is and how the pieces fit.
- **[Ecosystem](https://the-protobuf-project.org/ecosystem)**: every repository with its full documentation.
- **[Editor](https://the-protobuf-project.org/editor)**: what each plugin actually generates from one schema,
  recorded from the real binaries. Often the quickest answer to "what will this
  produce?"
- **[Blogs](https://the-protobuf-project.org/blogs)**: longer explanations of the design and the trade-offs.

## Ask a question

Open an issue in the repository closest to your question. If you're not sure
which one that is, pick the plugin you were running; we'll move it if needed.
Include:

- what you ran (the command, `buf.gen.yaml`, or plugin options),
- a minimal `.proto` that shows the problem,
- what you expected and what you got, and
- the plugin version (`protoc-gen-<name> --version`) and your OS.

## Report a bug or request a feature

Use the issue forms in the affected repository. See
[CONTRIBUTING.md](CONTRIBUTING.md) for what makes a report easy to act on.

## Security

**Do not open a public issue.** Follow [SECURITY.md](SECURITY.md).

## Stay up to date

Releases, project news, and security notes are posted on the
[announcements page](https://the-protobuf-project.org/announcements), also available as an
[RSS feed](https://the-protobuf-project.org/announcements/rss.xml).

## What to expect

The project is maintained by a small team. Questions and bug reports are usually
answered within a week. There is no paid support.
